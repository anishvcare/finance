# LifeLedger Pro - User Guide

## Getting Started

### 1. Create Your Account
- Visit the application URL
- Click "Register" or "Sign in with Google"
- Verify your email address (if using email registration)

### 2. Complete Onboarding
After first login, you'll be guided through setup:
1. Choose workspace type (Personal or Business)
2. Enter your business/personal details
3. Set currency and timezone
4. Configure invoice settings
5. Upload your logo
6. Add payment details (bank/UPI)

### 3. Understanding Workspaces
- **Personal workspace**: Track personal finances, tasks
- **Business workspace**: Full invoicing, products, customers
- You can have multiple workspaces
- Switch between workspaces from the sidebar

## Managing Products

### Add a Product
1. Navigate to Products
2. Click "Add Product"
3. Fill in: name, price, unit, tax rate
4. Optional: code, SKU, description, image, stock tracking
5. Save

### Price Management
- Each product can have multiple price levels
- Price changes are tracked in history
- Existing invoices keep their original prices

## Managing Services

### Add a Service
1. Navigate to Services
2. Click "Add Service"
3. Set hourly rate or fixed price
4. Configure tax settings
5. Save

## Managing Customers

### Add a Customer
1. Navigate to Customers
2. Click "Add Customer"
3. Enter name, email, phone
4. Add billing/shipping address
5. Set payment terms
6. Save

## Creating Quotes

### Create a Quotation
1. Navigate to Quotes → New Quote
2. Select customer
3. Add line items (products, services, or custom)
4. Adjust quantities, prices, discounts
5. Add notes and terms
6. Save as draft or send immediately

### Convert Quote to Invoice
1. Open an accepted quote
2. Click "Convert to Invoice"
3. Review the generated invoice
4. Finalise and send

## Creating Invoices

### Create an Invoice
1. Navigate to Invoices → New Invoice
2. Select customer
3. Set invoice date and due date
4. Add products, services, or custom items
5. Apply discounts and tax
6. Add payment instructions
7. Save draft

### Finalise and Send
1. Review the invoice preview
2. Click "Finalise" (assigns number, locks totals)
3. Click "Send" to email to customer
4. Or download PDF / print

### Record Payment
1. Open the invoice
2. Click "Record Payment"
3. Enter amount, date, method, reference
4. Save - balance automatically updates

## Managing Bills

### Record a Supplier Bill
1. Navigate to Bills → New Bill
2. Select supplier
3. Enter bill details and line items
4. Attach supplier's invoice image (optional)
5. Save

### Pay a Bill
1. Open the bill
2. Click "Record Payment"
3. Enter payment details
4. An expense transaction is created automatically

## Payment Screenshots (OCR)

### Import from Screenshot
1. Click "Scan Screenshot" on dashboard
2. Upload or capture a payment screenshot
3. Wait for text extraction
4. Review extracted details (amount, date, merchant)
5. Correct any errors
6. Link to existing invoice/bill or create new transaction
7. Confirm and save

## Tasks & Commitments

### Create a Task
1. Navigate to Tasks → New Task
2. Enter title, description
3. Set due date and priority
4. Assign to team member (if applicable)
5. Add subtasks if needed

### Create a Commitment
1. Navigate to Commitments → New Commitment
2. Enter details and due date
3. Add milestones
4. Link to customer/supplier/invoice if relevant

## Reports

### Available Reports
- **Sales**: Revenue by date, customer, product
- **Invoices**: Ageing, outstanding balances
- **Bills**: Supplier payables, ageing
- **Cash Flow**: Income vs expenses over time
- **Profit**: Revenue minus costs
- **Personal**: Budget tracking, category spending

### Using Reports
1. Navigate to Reports
2. Select report type
3. Set date range and filters
4. View charts and tables
5. Export to CSV or PDF

## Installing the App (PWA)

### On Android
1. Visit the app in Chrome
2. Click "Install App" button (or browser prompt)
3. App icon appears on home screen

### On iPhone
1. Open in Safari
2. Tap the Share button
3. Select "Add to Home Screen"
4. Confirm

### On Desktop
1. Visit the app in Chrome/Edge
2. Click the install icon in address bar
3. Or click "Install App" button in the app
